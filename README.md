# Angular + AI: 24-week learning repo

Following [AI Path for an Angular Developer 24-Week Plan](./AI%20Path%20for%20an%20Angular%20Developer%2024-Week%20Plan.md). Start: Mon 9 Nov 2026.

## Layout

- `phase-N-<topic>/`: one folder per phase, with a README of goals
  - `week-NN-<topic>/`: one folder per week
    - `README.md`: checklist, build task, time log
    - `01-<topic>.md`, `02-…`: one note per thing learned
    - `lab-<name>/`: small throwaway experiment for the week
  - `project-<name>/`: the shipped project for the phase (`PLAN.md` holds the intended structure; scaffold the code here)
